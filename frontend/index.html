Introduction

Overview.

Electrical engineering student building systems from hardware up.

Electrical Engineer & Embedded Systems

I am an Electrical Engineering student at NUST focused on building practical engineering solutions at the intersection of embedded systems, intelligent computing, and RF technology. My experience spans ESP32-based IoT systems, real-time telemetry, MQTT communication, Flask backend development, signal processing, and machine learning

My final year project, DroneGuard, is an anti-drone surveillance system that combines RF signal detection, embedded hardware, and machine learning for real-time drone identification. The system uses custom RF detection and jamming PCBs, Raspberry Pi-based control, multiple RF transceivers, and an RTL-SDR with GNU Radio for wideband signal analysis and classification. I work across the system from RF hardware and PCB design to signal processing, machine learning, and real-time software integration
